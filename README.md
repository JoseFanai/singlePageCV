# Single-Page CV
https://roadmap.sh/projects/single-page-cv

A simple single-page CV/resume website built using HTML. This project focuses on creating a clean, semantic HTML structure while implementing basic SEO, Open Graph metadata, and a favicon.

The project is designed as a foundation for future styling and responsive design.

## 📌 Project Overview

This project is a single-page CV containing sections for:

* Personal information
* Skills
* Education
* Career history / experience
* Social profiles

The main goal of the project is to practice writing **semantic HTML** and understanding how metadata improves a webpage's SEO and social sharing capabilities.

## 🧩 HTML Structure

The CV uses semantic HTML elements to make the content easier to understand and maintain.

Main elements used include:

* `<header>` — Personal information and contact details
* `<main>` — Main CV content
* `<section>` — Individual CV sections
* `<h1>` — Main page heading
* `<h3>` — Section headings
* `<p>` — Text content
* `<ul>` / `<li>` — Lists of achievements and skills
* `<footer>` — Social profile information

## 🔍 SEO

The page includes basic SEO metadata to help search engines understand the webpage.

```html
<meta name="description"
      content="Personal CV of Joseph, a Frontend Developer">
```

The page also includes a descriptive `<title>`.

## 🌐 Open Graph

Open Graph metadata has been added to improve how the CV appears when shared on social media platforms.

```html
<meta property="og:title"
      content="Jose Fanai - Frontend Developer">
```

## 🖼️ Favicon

A favicon is linked in the `<head>` section:

```html
<link rel="icon" href="favicon-32x32.png">
```

This displays an icon in the browser tab when the CV page is opened.
